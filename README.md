# Causal Probing for Internal Visual Representations in Multimodal Large Language Models

Data are avalible at 🤗<a href="https://huggingface.co/datasets/hehehahi4/Vis_diff">Vis_diff</a>. We construct paired images with and without specific concept, which isolate specific visual conceptual differences and provides a reliable foundation for our causal analysis. It contains four visual concepts: entity, visual style, emotion, abstract concept. 

Paper at [here](https://arxiv.org/abs/2605.05593).
